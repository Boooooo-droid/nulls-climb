# NULLS CLIMB

Unofficial, fan-made wall-jump climber for the [Nulls](https://x.com/nullsxyz) community. Not affiliated with Nulls. No wallet, no signup.

Tap / click / Space to jump wall to wall. Slice bombs and glitch bugs mid-jump for combos, grab memory fragments, the yellow DO NOT ERASE shield card and the rare golden memory card. Dodge ERASE blocks, ERASE lasers (sector 2) and falling corrupted blocks (sector 3+). 5 kills = REBOOT boost. Each loss switches to the next Null: GOLD GUARD (starts with shield) -> PURPLE CAP (longer combos) -> DENIM NULL (big magnet).

Nulls name, wordmark, memory card and bomb art belong to Nulls; used here as fan art.
