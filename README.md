# NULLS CLIMB

Unofficial, fan-made wall-jump climber for the [Nulls](https://x.com/nullsxyz) community. Not affiliated with Nulls. No wallet, no signup.

Tap / click / Space to jump wall to wall. Slice bombs and glitch bugs mid-jump, dodge ERASE blocks, grab the yellow DO NOT ERASE memory card for a shield, 5 kills = REBOOT boost. Each loss switches to the next Null.

Nulls name, wordmark, memory card and bomb art belong to Nulls; used here as fan art.
